Restaurant Table Order

A web-based Restaurant Table Ordering System that allows customers to view the menu and place food orders easily using a digital interface.

🌐 Live Website

👉 "Open Restaurant Table Order Website" (https://restaurant-table-order.onrender.com)

Features

- 🍽️ Digital restaurant menu
- 📋 View food items and prices
- 🛒 Add food items to order
- ➕ Increase or decrease item quantity
- 💰 Automatic order total calculation
- 📱 Responsive and user-friendly interface
- ⚡ Simple and fast ordering experience

Technologies Used

- HTML
- CSS
- JavaScript

Project Purpose

The purpose of this project is to provide a simple digital solution for restaurant table ordering. It helps customers select food items and manage their orders through an easy-to-use web interface.

How to Use

1. Open the live website using the link above.
2. Browse the available food items.
3. Select the required items.
4. Add items to the order.
5. Adjust the quantity if required.
6. Check the total amount.
7. Place the order.
